# Fight Night Combat Tournament

This html File can be used to display the Fight Night Combat Tournament bracket. 
It is closely based on the [Score Sheet](https://fightnightcombat.com/downloads/FightNightCombatTournamentScoreSheet.pdf) from the fightnightcombat.com website.

It works offline and can be used in any browser.
Just enter the names of the players and the results of the matches, and it will automatically update the bracket.

You can choose between 8 or 12 players for the final tournament.
